# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analysis project focused on understanding **customer shopping behavior, purchasing patterns, product performance, and customer preferences** using Python, SQL, and Power BI.

The project transforms raw customer shopping data into actionable insights through **data cleaning, exploratory data analysis, SQL analysis, and interactive dashboard visualization**.

---

## 📌 Project Overview

Understanding customer purchasing behavior is essential for improving sales, customer retention, product strategy, and marketing decisions.

In this project, customer shopping data is analyzed to answer questions such as:

* What are the most purchased product categories?
* Which products generate the highest sales?
* What are the purchasing patterns of different customer groups?
* How does customer behavior vary across different demographics?
* What payment methods are most commonly used?
* How do discounts influence purchasing behavior?
* Which customer segments contribute most to overall sales?
* What business strategies can be developed from the analysis?

---

## 🎯 Objectives

The main objectives of this project are:

1. Clean and prepare the raw customer shopping dataset.
2. Perform exploratory data analysis using Python.
3. Analyze customer and product trends using SQL.
4. Identify important purchasing patterns and customer segments.
5. Create an interactive Power BI dashboard.
6. Generate actionable business insights from the analysis.
